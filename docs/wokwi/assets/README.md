# Dibujos nativos de Wokwi

`wokwi-elements.json` contiene SVG y posiciones de terminales extraídos de
`@wokwi/elements` **1.9.2**, publicado por Uri Shaked y colaboradores:

- Repositorio: https://github.com/wokwi/wokwi-elements
- Paquete original: https://registry.npmjs.org/@wokwi/elements/-/elements-1.9.2.tgz
- Licencia original: [WOKWI-ELEMENTS-LICENSE](WOKWI-ELEMENTS-LICENSE), MIT.

Se usan los componentes `wokwi-pushbutton-6mm`, `wokwi-rgb-led` y
`wokwi-resistor`. Los colores de los pulsadores y las bandas de las resistencias
se establecieron mediante las propiedades de los componentes originales.
Se asignaron identificadores únicos a sus gradientes para combinarlos en el
mismo SVG. No se necesita descargar la biblioteca para abrir el diagrama.
